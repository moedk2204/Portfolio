AI Agent Projects

Medical Assistant — Multi-Agent Clinical RAG

LangGraph • Multi-Modal RAG
A safety-first medical question-answering agent built as a LangGraph state machine. An intake agent classifies clinical intent, a tiered retrieval agent searches authority-weighted Pinecone namespaces (clinical guidelines, drug monographs, StatPearls), and a compliance agent rewrites any answer that drifts into diagnosis or prescription language.
Python LangGraph LangChain Pinecone Gemini Vision Ollama (Local LLM) Sentence-Transformers FastAPI Supabase Gradio

Key Features

  • Three-node LangGraph pipeline (Intake → RAG → Safety) with conditional routing that short-circuits greetings, small talk, and out-of-scope questions before retrieval
  • Structured intent classification via a local LLM with Pydantic-parsed output and a keyword-based re-routing fallback when the classifier misfires
  • Deterministic namespace router mapping each question category to a primary vector namespace plus ordered fallbacks, with guideline-keyword overrides
  • Tiered fallback retriever that escalates across namespaces until average similarity clears the threshold — an explicit anti-hallucination layer
  • Authority-weighted confidence scoring blending retrieval similarity with source trust (guidelines > drug monographs > StatPearls)
  • Multi-modal ingestion using PyMuPDF4LLM + Gemini Vision to transcribe medical charts and figures into retrievable text, with a persistent transcription cache and rate-limit retry logic
  • Regex-based safety agent detecting and rewriting prescriptive language into guideline-attributed phrasing
  • Observability layer logging every query, namespace, similarity, and confidence to Supabase plus local JSONL backups
  • Served through both a FastAPI REST API and a Gradio UI exposing live pipeline telemetry (classification, namespace, confidence, sources)
